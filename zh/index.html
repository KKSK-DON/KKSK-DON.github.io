项目开源贡献简历

亮点

  • vLLM 贡献者——5 个 PR 合入主库，覆盖多模态性能优化、模型接入与核心重构；另有一个 FlashInfer ViT attention 后端提案。
  • INT8 KV cache 量化——静态量化在 GSM8K 全量与 HumanEval 上精度与 BF16 持平；同等显存下 KV cache 容量翻倍，Prefix Caching 命中率随之提升。
  • 多模态模型训练性能优化——用 torch.profiler trace 定位并消除同步点、融合小算子、让通信与计算重叠，H100 上以基线与优化版两份 trace 对照验证。
  • MoE All2All（对齐 DeepEP）——每层通信从 5 次 all2all 压到 3 次；双卡 NVLink H100 上与 DeepEP V2 对比，combine 输出精度对齐。
  • 手写 CUDA 算子——H100 上逐级优化：LayerNorm/RMSNorm 带宽利用率 81%，GEMM 达 cuBLAS 的 75%。
  • Truckpedia 生产级 LLM 服务——自托管 vLLM 部署 GLM-4.6V（107B MoE）：FP8 KV cache 离线校准达到 W8A8C8，选定 TP4×DP2+EP8 切分，用 profiler 定位 CPU 瓶颈后吞吐 1.86×。
